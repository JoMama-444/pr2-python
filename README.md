# Система регистрации сервисных обращений

Консольное приложение для регистрации и учёта обращений клиентов в сервисный центр.

## Возможности
- просмотр и поиск мастеров;
- добавление мастеров;
- регистрация сервисных обращений;
- проверка доступности мастера;
- поиск обращений по клиенту;
- статистика по типам устройств;
- сохранение и загрузка данных в JSON.

## Структура проекта
- `main.py` — точка запуска и меню;
- `requests.py` — работа с обращениями;
- `masters.py` — работа с мастерами;
- `storage.py` — сохранение и загрузка JSON;
- `utils.py` — безопасный ввод;
- `data/` — JSON-файлы данных;
- `tests/` — автоматизированные тесты.

## Требования
- Python 3.x
- pytest
- flake8
